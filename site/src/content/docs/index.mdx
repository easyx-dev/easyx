## 设计原则

<CardGrid>
  <Card title="独立发版">
    各库版本独立维护，推送 main 后仅发布版本号有变化的包，不强制版本对齐。
  </Card>
  <Card title="按需引入">
    每个库都提供完整类型声明，可单独安装、单独升级，互不牵连。
  </Card>
  <Card title="统一演示">
    所有库共用本站点，演示运行在独立页面中，与文档正文互不干扰。
  </Card>
</CardGrid>
