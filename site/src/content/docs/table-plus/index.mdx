`@easyx/tiptap-table-plus` 为 Tiptap 编辑器提供了全功能的表格增强，包括行列操作、单元格编辑、主题切换和国际化支持。

## 功能说明

TablePlus 提供以下能力：

- **插入表格**：支持自定义行列数的表格插入
- **行列操作**：插入、删除、上移、下移、左移、右移、复制、排序
- **单元格操作**：合并、拆分、清除内容、文字颜色、背景色
- **调色板**：70 色（10 色相 × 7 级明度），支持方向键导航，可作用于单元格文字与背景
- **表头切换**：切换标题行和标题列
- **主题切换**：浅色 / 深色模式实时切换
- **国际化**：中英文右键菜单切换
- **构建形态**：Bundleless ESM，每个源文件独立输出，支持 Tree Shaking 与按需加载
