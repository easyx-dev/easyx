## 内置能力

- **文本样式**：加粗、斜体、下划线、删除线、行内代码、下标、上标
- **标题与段落**：H1 ～ H6、引用、代码块、分割线、首行缩进
- **对齐与排版**：四种文本对齐、9 档字号（12px ～ 48px）、7 档行高（1 ～ 3）
- **颜色**：70 色文字前景色与背景高亮
- **列表**：无序、有序、任务列表
- **表格**：10×10 Grid Picker 插入，集成 [Table Plus](/easyx/table-plus/) 全部增强
- **链接**：链接编辑弹出层与 hover 快速操作
- **智能排版**：输入 `(c)` / `->` / `1/2` 自动替换为 © / → / ½
- **媒体**：图片（对齐 / 拖拽缩放 / 替代文本）、视频、音频、附件

## 创建方式

```ts
import { createEditor } from '@easyx/editor';

const editor = createEditor(container, {
  defaultContent: '<p>Hello World</p>',
  defaultTheme: 'light',
  image: {
    upload: async (file) => ({ id: file.name, url: '...', name: file.name, size: file.size }),
  },
});
```

完整参数见 [API 参考](/easyx/editor/api-reference/)。
