## 特性

<CardGrid>
  <Card title="零 UI 框架依赖">
    工具栏、气泡菜单与选中浮层均以原生 DOM 构建，可嵌入任意前端项目。
  </Card>
  <Card title="媒体能力">
    图片、视频、音频、附件均支持上传 / URL / 媒体库三种插入方式，粘贴与拖入的文件自动按类型路由。
  </Card>
  <Card title="高度控制">
    height / minHeight / maxHeight / resizable 四种配置覆盖自适应、定高与拖拽调节。
  </Card>
  <Card title="暗色主题">
    全部颜色由 CSS 自定义属性控制，setTheme() 运行时切换并同步表格主题。
  </Card>
</CardGrid>
